## 核心运营商二选一：MTN 还是 Moov？

　　贝宁的移动通信市场基本是双雄争霸，有点像国内的移动和联通，但规模小得多。

**MTN Benin** 是市场老大，信号覆盖广，特别是在城市和主要交通干道上。如果你需要频繁在科托努、波多诺伏、帕拉库之间往返，MTN 通常是更可靠的选择。它的用户最多，网点也随处可见，买个话费充值卡（Recharge Carte）非常方便。

**Moov Africa Benin**（以前叫Etisalat）则有点像挑战者，套餐价格有时会更激进一些，试图从MTN那里抢用户。在一些偏远地区，它的信号表现可能反而有惊喜。不过，它的营业厅网点相对少一点。

　　怎么选？如果你的活动范围以城市为主，求稳就选MTN。如果想省点钱，且主要在固定区域活动，可以试试Moov。想象一下，在Abomey-Calavi的仓库区，信号强弱可能直接决定你能否准时收到货主的消息。

## 2025年套餐价格与充值：多少钱才够用？

　　这里的资费模式和国内类似，也是先买基础套餐获得通话和短信，再额外购买数据包。价格每年都有些微调，但2025年大致是这个行情：

*   **SIM卡本身**：通常需要1000-2000西非法郎（约合12-24元人民币），里面可能包含少量初始话费。
*   **基础语音套餐**：很便宜，一个月大概500-1000西法，主要包含网内通话分钟数。
*   **数据流量包**：这是开销大头。对于短期商务或旅行者，按天或周购买更灵活。
    *   日包：约500西法，给你1GB左右的流量，刷刷地图、发发邮件够用了。
    *   周包：2000-3000西法，能有个5-7GB，足够你轻度使用一周。
    *   月包：如果你要长待，10000西法（约120元）左右可以买到20GB以上的套餐。

## 必做步骤：实名认证与APN设置

　　这是最关键也最容易卡住的一步！贝宁严格实行手机卡实名制。

**实名认证（Registration SIM）**：买完卡后，你必须带着护照和本地住址（酒店地址即可）去运营商的官方营业厅（Agence）办理登记。不完成这一步，卡用一段时间后就会被停机。我记得为了找MTN营业厅，在科托努转了半小时，所以最好买卡时就直接在营业厅买，一步到位。

**APN设置**：这可能是整个流程里最技术性的一环了。插卡后如果上不了网，十有八九是这里没设对。
*   **对于MTN**：手动新建一个APN，名称写“MTN Internet”，APN处写“internet.mtn.bj”，其他全部默认或留空。
*   **对于Moov**：同样新建APN，名称写“Moov”，APN处写“moov”，用户名和密码也都填“moov”。

　　设完记得保存并选中它，然后重启手机。嘿，有没有想起早年国内用GPRS上网时的感觉？

## 设备兼容与网络频段

　　贝宁的4G网络已经相当普及，主要城市都有覆盖。它采用的频段是：
*   3G：900MHz 和 2100MHz
*   4G/LTE：B3 (1800MHz) 和 B20 (800MHz)

　　这个频段组合和欧洲非常像，这意味着绝大多数国内带来的全网通手机都能完美支持。检查一下你的手机规格，只要支持B3和B20，网络连接就不是问题。至于5G？至少在2025年，对旅行者来说还不是需要重点考虑的事情。
